- **[SeroVerse Home & Core](https://seroverse.github.io/SeroVerse/)** (`SeroVerse/SeroVerse`) — Ecosystem overview, `seroverse.core` SoA/graph engine, and `seroverse.client` async API clients
- **[SeroRef](https://seroverse.github.io/SeroRef/)** (`SeroVerse/SeroRef`) — Single-pass bacterial & prophage ORF caller, 1D-CNN role classifier, and de novo locus segmenter & matcher

- **[SeroGen](https://seroverse.github.io/SeroGen/)** (`SeroVerse/SeroGen`) — Geno-glycomic enzyme-to-linkage alignment and Relational MPNN *de novo* structure predictor
- **[SeroEpi](https://seroverse.github.io/SeroEpi/)** (`SeroVerse/SeroEpi`) — Bayesian hierarchical sero-epidemiological modelling, LOSO-validated vaccine formulation, and interactive PyShiny web application
